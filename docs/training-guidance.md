# AI 훈련 참고 기준과 유산소 분포

확인일: 2026-09-14. 버전: training-guidance-2026-09-14-v2.

## 확인한 자료와 범위

- [ACSM 2026 공식 개정 요약](https://acsm.org/resistance-training-guidelines-update-2026/): 건강한 성인의 저항훈련. 지속성·개인화, 근력/근비대/파워에 따른 부하와 훈련량 차이를 간결하게 참고한다. [원 논문 DOI](https://doi.org/10.1249/MSS.0000000000003897). 공개 요약에서 확인한 내용만 코드에 반영했다.
- [NASM 공식 OPT 모델](https://www.nasm.org/certified-personal-trainer/the-opt-model): 안정화 지구력, 근력 지구력, 근비대, 최대근력, 파워의 조정 가능한 체계. 공개 현행 자료이며 별도의 2026 신판 확인을 의미하지 않는다.
- [NSCA 공개 부하 선택 교육 자료](https://www.nsca.com/education/articles/kinetic-select/intensity-or-resistance/): 2018 자료로 연도를 유지한다. 목적과 훈련 상태에 따른 부하 선택, 기구별 반복 능력 차이 및 국소 근지구력의 일반 원칙만 참고한다.
- [NSCA 교재 5판 출간 안내](https://humankinetics.me/2026/03/25/closer-look-to-nscas-newest-books/): 출판사가 2026년 3월 출간을 안내. [상품 정보](https://us.humankinetics.com/products/essentials-of-strength-training-and-conditioning-5th-edition-epub)는 ©2027 표기. 출간 여부와 교재 본문 열람은 별개다. 본문을 확보·검토하지 않았으므로 5판 전체를 학습하거나 근거로 사용했다고 표시하지 않는다. CSCS는 NSCA의 자격이며 별도 기관의 지침이 아니다.

## 실행 방식

`functions/training-guidance.mjs`에 출처·적용 범위가 있는 짧은 참고문을 둔다. `service.paid`에서 목표 설계, 목표 평가, 평가 해석, 종합 분석, 다음 수업, AI 도우미의 기존 요청에 붙인다. 모델 재학습이나 매 요청 웹 검색을 수행하지 않는다. 실제 Gemini countTokens 비교에서 참고문 추가분은 920토큰(기준 입력 40 → 960)이었다. 추가 생성 호출 0회. 출력 한도·기존 타임아웃은 유지한다. 이 수치는 입력 증가량이며 생성 완료시간의 실측 차이를 뜻하지 않는다. 판독·검색·검색 안전 검사에는 훈련 참고문을 넣지 않는다.

회원 자료와 일반 지침을 분리한다. 지정 목표와 기존 프로그램·기구·부하·가동 범위·회복 및 메모가 우선이다. 네 훈련 목적을 무조건 추천하지 않는다. 미측정 1RM/RIR/RPE/VO2max, 진단, 임의 개인 처방을 만들지 않는다. 볼륨을 근육 성장, 반복 합계를 단일세트 능력, 인터벌 구간을 완료 라운드로 해석하지 않는다. 모델은 기존 근거 후보·출력 스키마·검증 범위를 벗어날 수 없다. 일반 가이드 적용 시 짧게 자료명을 밝힌다.

호출 로그에 guidanceVersion을 기록한다. 기준 변경 시 리포트·목표 평가·평가 해석·다음 수업·채팅의 캐시 버전을 갱신한다. 이전 목표 평가를 새 기준 결과로 복사하지 않는다. 트레이너의 저장 계획·판단과 원본 기록은 덮어쓰지 않는다.

## 유산소

기록 수정의 운동 부위 선택, 판독 스키마, 서버 검증, Firestore 저장 규칙에 `유산소`를 추가한다. 명시한 부위가 우선이며 일반 근육 부위를 이름만으로 유산소로 바꾸지 않는다. 전신·미분류의 기존 자료는 명확한 유산소 기구/활동명 또는 경사·속도·시간 기록일 때만 보조 분류한다. 에어 바이크는 복근 동작과 머신이 동명이므로 이름만으로 분류하지 않는다. 사용자가 확인한 코어 에어 바이크는 코어 세트로 유지한다.

유산소는 시간·구간·날짜 수로 집계한다. 시간 누락은 미기록으로 남기고 반복수를 시간으로 환산하지 않는다. 근육별 세트 백분율에 유산소 시간/구간을 섞지 않는다. 요약·부위 분포·AI 요약·기존 프로그램 통계에 같은 분류 함수를 쓴다. 전체 시간은 기록된 회복 구간을 포함할 수 있고 완료 라운드를 뜻하지 않는다. 화면 표시와 집계만 바꾸며 기존 원본 데이터를 일괄 변경하지 않는다.

## 알림 배치

분석 오류 문구와 재시도 버튼은 한 줄 flex로 배치하고 기간 선택과 18px 간격을 둔다. 좁은 폭에서 긴 문구는 자신의 영역 안에서 가로로 확인할 수 있으며 버튼 위로 겹치지 않는다.

## 응답시간 확인 및 관찰한 오류

가상 푸시업 2개 날짜 자료로 기존/참고문 포함을 각각 2회 실행했다. 기존 1.89·1.45초, 참고문 포함 1.61·1.55초. 표본이 작으며 실제 회원의 긴 기록·서버 대기시간에 대한 보장이 아니다. 입력 증가량은 두 조건에서 920토큰으로 같았다.

참고문을 붙인 응답 하나가 반복수 증가로 근비대 향상을 확정했다. 목표 평가 검증기에 수행 기록만으로 근육 성장 확정을 표시하지 않는 검사를 추가하고 관찰된 답변을 회귀 테스트로 남겼다. 모델의 자유로운 근거 선택·일반 제안은 유지하며 이 오류는 판단 보류와 직접 측정 확인으로 바꾼다.
