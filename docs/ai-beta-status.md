## 승인 보류

클라우드 API 활성화 + 전용 제한 키 생성 + Secret Manager 저장 시도는 자동 승인 심사에서 거부됨. 해당 명령은 실행되지 않음. 유료 공유 클라우드 서비스 및 영구 자격 증명 변경의 구체적 권한 범위가 부족하다는 이유.
사용자가 잠든 동안 진행하라고 했지만 이 거부된 클라우드 변경을 우회하지 않음.
README의 ‘승인 후 적용할 구체적 범위’를 사용자에게 승인받은 뒤 배포해야 함.

승인 후: 동일 trainer-note-a9dd7에 필요한 API 활성화 → 서버 전용 키/Secret Manager → Functions 및 Rules 배포 → 실제 Auth/App Check/Gemini/큐 통합 확인 → 서버 플래그 활성화 → 기존 AI Logic 직접 호출 우회 차단. 모델 비용 제한은 Firebase 전체 청구 하드캡이 아님.

별도 운동 기록 입력/확정 화면을 기본 동선에서 제외. 업로드 직후 3패널 작업실에서 진행 분석을 먼저 표시하며, 왼쪽 실제 판독 표에서 잘못된 값만 인라인 수정. 원본·분석·수업 준비는 함께 표시. 수정 시 원본 재판독 없음, 수치 통계는 AI 없이 즉시 재계산, 실제 의미 있는 변경만 종합 의견/수업 초안 1회 묶음 갱신. 서버 배포 승인 대기 상태는 동일.

## 업로드 동선 최종 연결

- 서버 플래그와 관계없이 원본·분석·수업 작업실을 기본 화면으로 표시하며 예전 수동 AI 읽기 목록으로 돌아가지 않음.
- 업로드 팝업에서 저장 완료 후 원본 파일을 즉시 열고 요약 탭으로 전환. 일부 파일 실패 시 성공한 원본으로 이동하고 실패 건수 안내.
- 원본 탭을 기본으로 열고, 판독 기록 탭에서 필요한 값만 수정.
- 서버 연결 활성화 경로의 자동 분석·재열람 캐시·무재판독 수정은 에뮬레이터 브라우저 테스트 통과.
