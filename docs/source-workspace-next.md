## 회원 홈 (2026-09-12)

- 로그인·재접속·새로고침은 회원 카드 목록부터 시작한다. 첫 회원을 자동 선택하지 않는다.
- 카드는 실제 회원 이름·목표·일지 수·운동 항목 수를 표시한다. 이름 검색, 이름순/최근 등록순, 새 회원 등록을 지원한다.
- 카드를 클릭하면 기존 작업실의 진행 분석을 연다. 사이드바 회원 목록 또는 로고로 홈에 돌아온다.

- 최초 홈에서는 회원 목록만 읽으며 파일/분석 구독과 AI 요청은 회원을 선택한 뒤 시작한다.
- 실제 컴포넌트와 전체 스타일, 가상 Firebase 데이터로 재접속·검색·정렬·등록 창·회원 진입·편집 보존·다른 회원 이동 확인·390px 홈·빈 회원 목록을 검증했다. 실제 계정 데이터는 변경하지 않았다.

## 화면

- 기본 2뷰: 유지되는 원본 + 가운데 `기록 수정 / 진행 분석 / 다음 수업` 탭. 최초 화면은 진행 분석이다.
- 2뷰는 원본과 작업 영역을 50:50으로 시작하고, 가운데 구분선을 드래그해 조절한다. 3뷰는 두 구분선으로 인접 영역을 조절한다. 조절한 비율은 모드별로 보관하여 탭 전환에도 유지하며 더블클릭 또는 Enter로 초기화한다. 방향키로도 조절할 수 있다. 원본 파일을 이동하거나 작업 탭을 변경해도 작성 중인 수정·수업 메모를 유지한다.
- 중복 상단 헤더 두 줄은 제거했다. 2뷰·3뷰는 작업 탭 옆에, 회원 정보·삭제는 사이드바 회원 관리에, 일지 추가는 원본 툴바와 회원 관리에 둔다.
- 분석·다음 수업에서는 원본을 접어 작업 영역을 넓힐 수 있다.
- 3뷰: 오른쪽 AI 도우미 패널을 연다. 좁은 화면에서는 도우미를 보조 패널로 띄운다. 모바일에서는 원본과 작업 영역을 위아래로 배치한다.
- 판독 기록도 모든 파일을 원본과 같은 순서로 묶어 연속 표시한다. 파일 선택은 필터가 아니라 해당 기록 위치로 이동하며, 판독 중·오류·연도 보완은 파일별로 유지한다. 직접 입력 및 연결 원본이 없는 기록은 별도 묶음으로 표시한다.
- 여러 PDF·PNG·JPEG를 같은 스크롤에 표시한다. 뷰어를 탭마다 다시 마운트하지 않으므로 원본을 다시 다운로드하지 않는다.
- 도우미 입력창 위의 `특정 부분을 선택해서 질문하기` 카드 또는 원본 툴바의 `영역 선택`을 누르면 도우미를 잠시 접어 원본을 드래그하기 쉽게 한다. 사각형을 드래그하거나 `이 페이지 전체 질문`을 누르면 선택 부분을 질문에 첨부하고 3뷰 도우미를 다시 연다. 아직 자유곡선 올가미는 아니다.
- 다음 수업의 운동별 추천 근거와 원본 기록 이동, 편집·저장 기능을 유지한다.

## 실제 Gemini 도우미

- `functions/chat.mjs`: 질문·선택 이미지·답변 검증, 프롬프트와 응답 스키마.
- `functions/service.mjs`의 `chat`: 로그인 UID로 회원/원본/이전 대화를 확인하고, 최근 최대120개 기록·선택 파일의 판독·분석·기존 수업 계획을 맥락으로 사용한다.
- 같은 요청 ID는 재결제하지 않는다. 서버에 완료된 답변을 저장한다. 동일 ID로 다른 내용을 보내면 거부한다. 실패한 요청의 새 시도는 명시적으로 실행한다.
- 기존 월/일/프로젝트 AI 원가 제한과 토큰 계량을 사용한다. 답변 출력은 최대1800토큰이다.
- 질문은 최대1200자, 선택 JPEG는 최대375KB. 선택 이미지를 질문에 첨부할 때만 Gemini로 보낸다. 대화 DB에는 원본 파일·페이지·좌표·이미지 해시만 저장하며 선택 이미지 본문은 저장하지 않는다.
- 도우미는 기록·프로그램을 자동 수정하지 않는다. 답변의 기록 근거 ID를 서버에서 검증한다. 대화는 해당 회원을 소유한 트레이너만 읽고, 클라이언트 직접 쓰기는 금지한다.

## 복합 운동 판독

- 판독 버전 `workout-v2-compound`: 독립 운동이 한 원문 행에 함께 있으면 `components`를 통해 2~4개 운동으로 분리한다. 부모 행에는 sets를 넣지 않는다.
- 예: `Cable ext + DB curl`, `20/5 kg`, `8/10 reps` → 익스텐션20kg8회 / 컬5kg10회.
- 원문·페이지·묶음 ID·분리 순서·값 대응 설명을 보존한다. 부모+자식 동시 집계, 동일 종목 중복 분리는 거부한다.
- 불분명한 무게/횟수는 null로 남겨 해당 운동만 확인 대상이 된다. 단일 복합관절 운동, 클린앤저크, 좌우 표기는 둘로 나누지 않는다.
- 새 판독부터 적용한다. 이미 저장된 과거 판독은 유료 일괄 재실행하지 않는다.
