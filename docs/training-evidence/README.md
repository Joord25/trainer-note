# 회원 목표를 해석하는 근거 기반 — 1차 정리

검토일: 2026-10-09 · 범위: 일반 성인의 체중·체지방 관리, 기초체력, 저항·유산소 구성과 배치.

## 우리가 만들려는 판단

**회원이 원하는 변화 → 확인된 현재 상태와 가능 조건 → 실제 기록 → 관련 연구의 기준 → 다음 수업에서 할 일**

예상 능력을 연령·성별 평균으로 정하는 기능이 아니다. 회원이 실제로 수행한 조건과 확인된 평가를 출발점으로 삼고, 다음 수업의 반응에 따라 조정하는 기능이다.

| 확인할 것 | AI가 읽을 근거 | 안내할 내용 | 피해야 할 결론 |
|---|---|---|---|
| 다이어트 목표와 구성 | 목표, 큰 근육군 저항운동 참여, 유산소 기록, 일상 활동·식이 정보 | 감량 과정에서 각 운동의 역할, 확인 후 보완할 구성 | 큰 근육 운동만 하면 감량 / 특정 부위의 정답 비율 |
| 유산소 운동량 | 주별 기록 시간, 빈도, 기구, 강도·작업/회복 표기 | 기록에서 확인되는 양과 빠진 정보, 지속 가능한 조정 | 시간 누락=0분 / PT 밖 운동 없음 / 기록 시간 전부 중등도 |
| 저항운동의 성격 | 세트별 반복·중량, 좌우, 수행 여유, 목적 | 저반복 경향의 지도 의도와 다른 구성 확인 | 1–5회면 무조건 최대근력 / 다이어트와 무조건 충돌 |
| 코어의 역할 | 동작·부위·측정 방식, 다른 동작과 연결 | 안정성·조절·힘 전달 등 실제 목적 확인 | 코어 비율을 높이면 복부 지방 감소 |
| 배치와 회복 | 같은 날 구성, 문서상 순서, 실제 순서·피로 메모 | 목표에 중요한 운동의 품질과 회복을 확인하는 조건부 제안 | 근력→유산소만 정답 / 문서 순서=실제 수행 순서 |
| 변화의 성과 | 같은 조건의 수행 기록, 체중·허리둘레·체성분 등 실제 측정 | 운동량 변화와 신체 변화 분리 | 볼륨 증가=근성장 / 연구 평균=개인 예상 감량 |

## 분석과 AI 도우미의 역할 구분

분석은 실제 앱 데이터인 부위 구성·총볼륨·세트·중량과 반복·종목별 추이를 연결한다. 같은 총볼륨 증가라도 세트가 추가된 것과 같은 세트에서 반복이 늘어난 것은 다르게 설명한다. 종목이 다른 볼륨을 능력 순위로 비교하지 않는다.

식단·영양 등 데이터가 없는 영역은 현재 회원 상태를 분석한 것처럼 쓰지 않는다. 다이어트 관련 목표의 다음 수업 방향에는 **AI 도우미로 식단·영양 상담을 이어가는 버튼**을 제공한다. 버튼은 필요한 정보를 묻는 질문을 채팅 입력에 준비한다. 자동 전송·자동 식단 생성·추가 AI 호출은 하지 않는다. 사용자가 확인하고 대화를 이어간다.

## 수집한 자료를 읽는 방법

[출처 목록](./sources.md)은 공식 지침·합의문, 체계적 고찰/메타분석, 기관 교육 자료를 구분한다. 논문 제목·발행연도·대상·링크·확인 범위·적용 한계를 함께 보존한다. 원문 전체를 앱에 복제하지 않고 짧은 요약만 제공한다.

- 대한비만학회의 지침은 국내 비만 성인에서 큰 근육군 저항운동과 유산소의 병행을 뒷받침한다. ‘다이어트’라고 입력했다는 이유로 비만이라고 진단하지 않는다.
- ACSM의 저항운동 기준과 체중 관리 합의문은 목적별 훈련 설계에 사용한다.
- 유산소 용량반응, 식이 감량 중 저항운동, 병행훈련과 순서 연구는 특정 질문의 보조 근거다.
- NASM·NSCA 교육 자료는 지도 방법의 틀이다. 임상 진료지침이나 메타분석과 같은 근거 수준으로 표시하지 않는다.
- SCI 등재·IF·인용 수만으로 신뢰도를 점수화하지 않는다. 연구 설계, 대상 적합성, 비교 대상, 결과의 일관성, 불확실성이 먼저다. 이번 목록은 체계적 문헌고찰 자체가 아니라 목적에 맞게 선별한 1차 근거 목록이다.

## 회원 정보: 아는 것과 확인할 것

| 정보 | 현재 앱에서 사용하는 경로 | 해석 원칙 |
|---|---|---|
| 주·보조 목표, 상세 목적, 초기 상태 | 저장된 훈련 목표와 회원 생성 목표 | 임의로 새 목표를 만들거나 우선순위를 뒤집지 않음 |
| 연령·성별·경력·증상·생활 조건 | 회원 배경/목표/날짜별 메모에 명시된 경우 | 없으면 미상. 이름으로 추정하지 않음. 과거 증상을 현재로 간주하지 않음 |
| 현재 수행 | 확인된 운동 기록·세트·단위·수행 조건 | 최대 능력·예상 능력과 구분 |
| 수업 빈도·회당 가능 시간 | 수업 계획 설정에서 선택한 값 | 과거 기록일 수를 예정 빈도로 바꾸지 않음 |
| 전체 주간 활동량 | PT 밖 활동까지 명시된 경우에만 해석 가능 | 업로드 기록으로 전체 주간 권고 충족 여부를 판정하지 않음 |

현재 회원 생성에는 연령·성별·경력 등을 모두 담는 독립 구조화 입력이 없다. 별도 평가 결과 컬렉션도 이번 회원 변화 분석에 새로 연결하지 않았다. 따라서 기록/메모에 없는 조건이나 측정 결과를 안다고 가정하지 않는다. 다음 확장 시 입력 항목과 평가 연결을 먼저 보완해야 한다.

## 실제 안내의 형태 — 합성 사례

가정: 목표는 체지방 관리, 최근 PT 기록에는 하체 저반복 운동과 코어가 있고 유산소 시간은 미상이며 개인 운동은 기록되지 않음.

> 하체 저항운동은 확인되지만, 이 기록만으로 주간 유산소량과 전체 구성을 평가하기는 어렵습니다. 다음 수업 전 개인 유산소의 시간·강도와 저반복 훈련의 지도 목적을 확인하겠습니다. 별도 유산소가 없다면 현재 수행과 가능한 시간을 기준으로 유산소 구간을 넣는 방향을 검토하고, 기록된 큰 근육군 운동은 다른 부위의 참여와 회복 상태를 함께 보겠습니다.

이 예시는 실제 모델 응답이나 특정 회원 처방이 아니다. 목표와 기록의 연결 → 결론에 필요한 확인 → 결과에 따른 행동이라는 답변 구조의 예다.

## 이번에 프로그램에 연결한 범위

- `functions/coaching-evidence.mjs`: 11개 출처와 목표 중심 해석 원칙. 버전과 검토일 보존.
- `functions/goal-program-context.mjs`: 최근 기록일 기준 28일, 월요일 시작 주별 기록 요약. 주 부위 참여, 횟수 운동 세트/기타 구간과 숫자 중량의 총볼륨, 유산소 기록 시간과 누락, 세트별 저반복 관찰을 계산.
- `functions/training-guidance.mjs`: 기존 3개 일반 훈련 참고에 목표별 근거를 추가. 회원 변화와 수업 계획 호출에만 전달. 채팅·판독에는 일괄 삽입하지 않음.
- `functions/coaching-workflow.mjs`: 초기 목표·회원/수업 메모·이력과 새 요약을 함께 전달. 근거 버전을 분석 입력 식별에 반영. 목표 설명의 개인 근거 ID와 출처 ID를 서버에서 검증하며 모델이 생성한 URL을 사용하지 않음. 회원 변화는 앱에서 이미 사용하는 3.5 심층 모델의 medium 추론으로 실행.

이는 추론 시 참고 자료를 제공하는 방식이다. 모델을 다시 학습시킨 것이 아니다. 참고 출처의 존재가 모든 생성 문장의 정확성을 보장하지 않으므로, 계산 회귀검사와 합성 사례의 실제 응답 검토를 분리한다.

기존 차트와 방향 분류는 유지하며, 앞에 목표와 실제 기록의 연결을 설명하는 짧은 항목과 검토된 출처 링크를 추가한다. 다이어트 목표에는 상담 연결 버튼도 제공한다. 이번 작업은 자료·판단 기반을 먼저 연결하는 단계다. 새 후보 운동 생성, 목표 적합도 점수, 자동 진단, 모든 질환·임신·청소년의 개별 처방은 범위에 포함하지 않는다.

## 근거를 계속 쌓는 규칙

1. 답하려는 질문을 먼저 정한다. 예: ‘감량 중 저항운동의 역할’, ‘유산소 배치와 근력 발달’.
2. 공식 지침과 원 연구/체계적 고찰의 대상·비교·결과를 확인한다. 초록만 확인하면 그대로 표시한다.
3. 문장별 적용 범위와 금지할 과잉 해석을 기록한다. 새 출처와 충돌하면 대상·목적 차이를 먼저 확인한다.
4. 현재 회원 자료로 판정 가능한지 확인한다. 없으면 필요한 측정/질문을 정한다.
5. 누락·충돌·희소 기록·가상 조건의 합성 사례를 검증한 뒤 근거 버전을 갱신한다.

대한비만학회 2024 개정의 별도 공개 논문은 진단·약물 치료 중심이므로 이번 운동 기준의 근거는 운동 권고를 확인한 2022 개정판(2023년 발행)으로 명시했다. 검토일은 자동 최신성을 보장하지 않는다. 문헌 추가·갱신은 검토 후 반영한다.
