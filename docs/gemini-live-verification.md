# Gemini 실제 연결 검증 · 2026-09-11

## 환경과 범위

Firebase `trainer-note-a9dd7`, `us-central1`, 모델 `gemini-3.1-flash-lite`, 리포트 `trainer-judgment-v3`. 테스트 자료는 가상 회원의 PDF 한 개(3개 날짜, 바벨 백 스쿼트 40kg, 총 6세트)이며 실제 회원 원본은 변경하지 않았다. 모델 응답을 흉내 내지 않고 실제 Gemini API와 배포된 작업 큐·Firestore를 사용했다.

## 발견하고 수정한 문제

1. Secret Manager 버전 1의 값이 현재 프로젝트 Gemini 키와 달랐고 countTokens/generateContent에서 401 `ACCESS_TOKEN_TYPE_UNSUPPORTED`가 발생했다. 현재 프로젝트의 기존 키를 메모리에서 검증한 뒤 버전 2로 저장하고 함수를 재배포했다. 새 Gemini 키를 만들거나 키를 채팅/Git에 노출하지 않았다.
2. 실제 Gemini가 판단 보류를 적용 제외로 바꾸거나 해당 카드에 허용되지 않은 기록 ID를 인용하여 검증에서 거절됐다. 카드별 응답 슬롯/열거값/허용 인용을 스키마에 고정했다. 빈 배열 길이 0 제약이 지켜지지 않아 허용 근거 없음은 `none`으로 고정하고, 서버가 검증 후 빈 배열로 변환한다. 잘못된 모델 판단을 그대로 통과시키지 않는다.
3. 한국 시간 오전의 당일 후속 결과가 UTC 날짜 때문에 미래로 취급되는 경계를 수정하고 테스트했다.

## 실제 성공 결과

- 파일 저장 완료 이벤트 → 판독 자동 실행 → 3개 행 자동 잠정 기록 저장.
- 3개 날짜, 6세트, 기록 볼륨 2,560 kg·회. 계산은 서버 코드.
- 종합 의견, 판단 카드 5개, 근거가 포함된 바벨 백 스쿼트 다음 수업 초안 저장.
- 조건 미확인 시 판단 보류. 가상 트레이너의 동일 조건·목표 기준을 저장한 뒤 진행 유지 후보/정체 적용 제외/계획 자료 부족으로 구분.
- 같은 입력의 실제 작업 큐 재요청 전후 AI 호출 문서 수 7→7, 리포트 지문 동일, 상태 ready. 중간 실패를 포함한 누적 수치이며 새 Gemini 호출은 0회.
- 가상 트레이너의 판단과 기대와 다른 당일 후속 결과를 저장한 뒤, 실제 배포 서버의 다음 리포트에 사례 1건·후속 결과가 포함되고 카드의 caseIds에서 해당 판단을 인용한 것을 확인했다. 이 추가 리포트는 입력 3,723 / 출력 1,459 토큰, 추정 $0.003120이었다.
- 기존 Firebase AI Logic SDK의 직접 countTokens 요청은 브라우저 키 제한으로 차단됨을 확인했다.
- 실제 App Check 토큰 발급 HTTP 200. App Check 없는 callable HTTP 401, App Check가 유효해도 로그인 없으면 HTTP 401.

판독 1회: 입력 1,197 / 출력 560 토큰, 요금표 추정 $0.001140.
성공한 조건 반영 리포트 1회: 입력 3,330 / 출력 1,353 토큰, 추정 $0.002862.
이 가상 자료의 판독+분석 합계는 약 $0.004002. 진단용 재시도 비용은 별도이며 모든 서비스 호출은 사용량 원장에 기록했다. 실제 파일 크기·기록 수에 따라 달라지고 Firebase 서버/저장소/네트워크 비용은 포함하지 않는다.

## 적용 상태

Functions 5개 및 규칙 배포, Secret 버전 2, localhost:3001 서버 AI 활성화. 기존 브라우저 AI Logic 직접 호출 경로는 브라우저 키 API 제한에서 제거. Auth·App Check·Firestore·Storage 허용 유지. 빌드 산출물 보관 7일.

`npm run test:all` 167개 및 production build 통과. 에뮬레이터 브라우저에서 실제 컴포넌트의 업로드/수정/판단/결과/모바일 동작을 확인했다. 운영 Google 계정으로 로그인한 브라우저의 전체 동선과 다양한 손글씨는 추가 사용 검증 대상이다. 가상 자료 성공은 예측 정확도·전문가 합의·모델 미세조정을 의미하지 않는다.

최종 로컬 화면에서 서버 AI 활성화 안내 렌더링을 확인했다. 가상 테스트 계정·회원·원본·판독/보고서 자료는 검증 후 삭제하며 프로젝트 전체 모델 원가 집계는 유지한다.
